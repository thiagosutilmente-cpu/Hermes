Dentro do próprio aplicativo do motoboy, existe o botão de indicação viral. O sistema gera automaticamente um código único para cada entregador.

* **Regra Recomendada:** A cada parceiro que baixar o aplicativo pelo link ou código do motoboy, o indicador ganha **7 dias extras de assinatura Pro** ou **R$ 5,00 no Pix**.
